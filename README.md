# Bitcoin Mining Farm Calculator

This is a web-based calculator for modeling a Bitcoin mining farm business in Neuquén, Argentina. It simulates profitability over 8 years, considering expansions, costs, and real-time data.

## Features
- Input parameters for investment, hashrate, energy costs, etc.
- Real-time BTC price and network difficulty fetching.
- Calculations in both USD and BTC.
- Projections with charts.
- Excel export.

## Installation
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `python app.py`
3. Open http://127.0.0.1:5000/ in your browser.

## Usage
- Fill the form with your parameters.
- Results update automatically as you type.
- Export results to Excel.

## Notes
- This is a simplified model. Real-world factors may vary.
- API integrations are placeholders; ensure API keys if needed.
